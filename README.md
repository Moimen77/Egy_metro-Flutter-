
# Egypt Metro Navigator 
By مؤمن عادل الحسانين ديغم

A Flutter application for navigating the Cairo Metro network.

## Features

- Calculate routes between metro stations.
- Display metro stations on an interactive map.
- Find the nearest metro station using the user's location.
- Search for places and find the nearest metro station.
- Display journey details, including stations, transfers, time, and ticket price.

## Tech Stack

- Flutter & Dart
- GetX
- OpenStreetMap
- flutter_map
- Geolocator

## Architecture

The project follows a feature-based architecture with
separation between UI, data, and business logic.
